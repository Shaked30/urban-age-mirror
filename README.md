## 🎯 Project Summary

Urban Age connects building residents with construction companies for urban renewal (TAMA) projects in Israel.

**Primary Goal:** Lead generation (get residents to submit building details)

**Design Direction:** Friendly + Professional balance
- Simple, clear, approachable
- Warm but credible
- Mobile-first, Hebrew/RTL
