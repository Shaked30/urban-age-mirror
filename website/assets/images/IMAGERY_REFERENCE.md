## 📋 Image Optimization Guidelines

### For Future Images

**Team Photos:**
- Format: JPEG
- Size: 800x800px minimum (square aspect ratio)
- File size target: < 200 KB each
- Quality: 85% JPEG compression
- Style: Professional but approachable

**Project Photos:**
- Format: JPEG for photos, PNG for visualizations with transparency
- Max dimensions: 2000px (largest side)
- File size target: < 1 MB per image
- Quality: 80-85% JPEG compression

**Logo:**
- Primary: SVG (vector, infinitely scalable)
- Fallback: PNG with transparency, 1000px width
- File size: < 50 KB

**General Guidelines:**
- Always optimize before uploading
- Use WebP format when browser support allows (better compression)
- Provide multiple sizes for responsive images
- Use lazy loading for below-the-fold images
